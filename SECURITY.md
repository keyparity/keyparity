# Security

Please don't report a vulnerability in a public issue.

Report it privately instead, at https://github.com/keyparity/keyparity/security/advisories/new (the **Report a vulnerability** button on the **Security** tab), and tell us what you found, how to reproduce it, and which version you tried. Only the maintainers can see the report.

We'll reply within a week, and we'll credit you in the advisory unless you'd rather we didn't.
